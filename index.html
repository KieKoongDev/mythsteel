Steel of legend

เกมแอ็กชันยุคกลางแฟนตาซี ฟันตามทิศเมาส์ ปัดป้อง หลอกล่อ สงครามสองกองทัพนับร้อยคน ดันรถกระทุ้งทลายประตูปราสาท สังหารกษัตริย์ทรราช ลานประลอง และล่าอสูร เล่นคนเดียว กับเพื่อนในวง LAN หรือออนไลน์

A dark-fantasy medieval action game: aimed cuts, parries and feints, two armies of a hundred men, a battering ram for the castle gate and a usurper king to slay, the arena, and monster hunts. Play solo, over LAN or online.

ดาวน์โหลดและติดตั้ง

Download and install

ไม่ต้องติดตั้งอะไรเพิ่ม แตกไฟล์แล้วเปิดเล่นได้เลย ไฟล์ใหญ่ประมาณ 500 MB

Nothing else to install: unzip and play. About 500 MB.

Windows

Windows 10 / 11 · 64-bit
  1. กดดาวน์โหลด Mythsteel-Windows.zip
  2. คลิกขวาที่ไฟล์ → Extract All (แตกไฟล์)
  3. เปิด Mythsteel.exe
  4. ถ้าขึ้น “Windows protected your PC” กด More info → Run anyway (เกมยังไม่ได้ซื้อใบรับรอง)
  5. เล่นออนไลน์ครั้งแรก Windows Firewall จะถาม ให้กด Allow
  1. Download Mythsteel-Windows.zip
  2. Right-click it → Extract All
  3. Open Mythsteel.exe
  4. If “Windows protected your PC” appears, click More info → Run anyway (the game is not code-signed yet)
  5. The first time you play online, allow it through Windows Firewall

macOS

macOS 11+ · Apple Silicon & Intel
  1. กดดาวน์โหลด Mythsteel-macOS.zip แล้วดับเบิลคลิกเพื่อแตกไฟล์
  2. ลาก Mythsteel.app ไปไว้ใน Applications
  3. ครั้งแรก: คลิกขวา (Control-คลิก) → Open → Open
  4. ถ้ายังเปิดไม่ได้: System Settings → Privacy & Security เลื่อนลงกด Open Anyway
  1. Download Mythsteel-macOS.zip and double-click to unzip
  2. Drag Mythsteel.app into Applications
  3. First launch: right-click (Control-click) → Open → Open
  4. Still blocked? System Settings → Privacy & Security, scroll down, Open Anyway

ลานประลอง — ดวล ศึกทีม 1v1 ถึง 5v5 ศึกยึดพื้นที่ ตะลุมบอน ร่วมมือต้านฝูง ล่าอสูร ในลานประลองยุคกลาง ลานคบเพลิง โคลอสเซียม หรือบนเรือไวกิ้ง
Arena — duels, team battles from 1v1 to 5v5, Conquest, free-for-all, co-op against the horde and monster hunts, on the tournament grounds, in the torchlit ring, the Colosseum or on a Viking longship

เล่นกับเพื่อน (LAN / ออนไลน์)

Play with friends (LAN / online)

คนเปิดห้อง (Host)

The host

  1. หน้าแรก → ห้อง → + สร้างห้อง เลือกตัวละคร
  2. มุมขวาบนจะขึ้น Room code (เช่น K7PQ-3M2X) และ IP ในวง LAN ส่งให้เพื่อน
  3. เกมจะขอให้เราเตอร์เปิดพอร์ต UDP 7777 ให้อัตโนมัติ (UPnP)
  1. Home → Rooms → + Create room, pick your fighter
  2. A room code (e.g. K7PQ-3M2X) and your LAN address show top right: send them to your friends
  3. The game asks your router to open UDP port 7777 by itself (UPnP)

เพื่อนที่เข้าร่วม

Joining

  1. หน้าแรก → ห้อง → พิมพ์ room code (ออนไลน์) หรือ IP ของเพื่อน (วงเดียวกัน) → เข้าร่วม
  2. ถ้าเชื่อมไม่ได้: ให้ host เปิด Port forwarding UDP 7777 ที่เราเตอร์ หรือทั้งคู่ใช้ VPN แลนเสมือนฟรี (Radmin VPN, ZeroTier, Tailscale) แล้วพิมพ์ IP ของ VPN
  3. เล่นได้สูงสุด 4 คน ที่เหลือเป็นทหารคอมพิวเตอร์
  1. Home → Rooms → type the room code (online) or your friend's IP (same network) → Join
  2. Can't connect? The host forwards UDP 7777 on the router, or you both use a free virtual LAN (Radmin VPN, ZeroTier, Tailscale) and type the VPN address
  3. Up to 4 players; the armies are the computer's

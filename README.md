# Mythsteel

Dark-fantasy medieval action: aimed cuts, parries and feints, armies of a hundred, sieges, the arena. Solo, LAN or online.

**Download and how to install:** https://kiekoongdev.github.io/mythsteel/

Downloads are on the [Releases](https://github.com/KieKoongDev/mythsteel/releases/latest) page (Windows and macOS). This repository holds the download page and the update manifest the game reads; the game's source is kept elsewhere.
